# 长短篇制作与发布计划

## 持续规则（2026-10-31用户确认）

- 每轮先定一部长线故事，再按其预计制作周期和现有成片库存选择前面发布的短故事；短篇数量不固定，不套用固定三个或固定安全库存阈值。
- 目标是每周至少发布一个完整故事。长篇允许间隔更久，不以单回处理完毕冒充整部可发布。
- 频道评论区的实际点名需求优先于外部单一播放样本；《卿卿误我》已有较多用户点名需求，不能机械沿用外部暂排名次。
- 排期计入Windows Mask/导出、传输、云端处理、验收和可能返工。按真实速度滚动调整，不把估算当截止承诺。
- 短篇优先取得可发布成片，长篇可同期准备。云端仍单回处理，按已完成回目边界安排，不为排期打断活跃分段或重复处理。
- Windows定时任务只跟踪交付、接收和回执清理，不例行巡查云端生产；用户主动问进度时可以单次查询。Linux继续已有托管目标。
