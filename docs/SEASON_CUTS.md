# 四季原片裁切

目标与第一季已确认成片一致：去掉动画、故事名和回目卡，从实际入场/锣鼓开场保留；结尾保留收束及其后的远景，在飞入Logo、转场、预告或独立片尾画面前结束。允许向内多切一点，初切始终 stream copy。没有入场或远景的原片按实际镜头记录，不能为套模板删掉正文。名单若已叠在尚未结束的正文/收束镜头上，记录这个例外，不能仅因名单出现就截断最后一句和“好”。

片头时长的复用范围是**同一季内部**，不是四季共用30秒。各季profile中的 `cut_review.opening_search_seconds` 是定位窗口，不是已批准的统一切点。每份新原片仍须检查边界，遇到不同版本可覆盖。S01旧 `cut` 字段和已确认裁片不变；其 `first_white_frame` 只用于既有普通集路径，不作为四季通用判据。

## 可执行流程

`scripts/cut/season_cut.py` 独立用于四季初切，不切换现有S01生产配置，不上传、不启动OCR、Mask或云端Worker。

1. `inspect --source <原片> --output <新审看片目录>`：源SHA、独立季profile SHA、实际时长、片头定位窗口和最后240秒网格、临近EOF图片写入 `audit.json`；查看 `contact.jpg` 和单张图片。输出目录必须是新的。
2. 用 `inspect --times <逐个秒数> ...` 建立精查目录：在已找到的片头、结束收束和第一处不应保留画面附近密集采样。每个裁切标记附近1秒内都必须有真实图片；不能凭粗网格或固定尾长批准。
3. 看完后 `plan --audit <精查audit.json> --first-live <首个干净现场秒数> --keep-through <必须保留到的收束/远景秒数> --first-forbidden <最早片尾转场秒数> --tail-kind logo_transition --note <实际查看范围和例外> --output <新plan.json>`。类型还包括 `preview`、`credits`、`clean_eof`；最后一种必须绑定真实EOF。不要把舞台布景上的静态Logo或普通角标当飞入转场。
4. `cut --plan <plan.json> --output <新裁片.mp4>`：重新核对源完整SHA，向内取下一个关键帧，原编码复制；尾端预留0.25秒安全量及0.5秒重排余量。校验首帧解码哈希、轨道/编码/尺寸、实际视频包末端不越界且保住所需收束镜头，以及首尾各2秒AV实际解码。失败保留partial，拒绝覆盖旧媒体或收据。
5. 查看新裁片首尾，确认没有标题、飞入Logo、预告/片尾信息，并保留收束镜头，再进入后续流程。`.cut.json` 只写真实技术结果，明确 `output_visual_review_pending=true`，不会自动冒充视觉验收或成片质量收据。

以上每个命令均以 `python scripts/cut/season_cut.py` 开头；路径带空格需引号。审看片、计划、媒体和收据留在仓库外 `.kwjd/season-cut-audit` / 工作媒体目录，不提交Git。检查图片需要Pillow，裁切/探测需要现有FFmpeg与FFprobe。

stream copy的边界受GOP限制。若关键帧跳过过多开场，或尾端安全量会吃掉必须保留的远景，工具拒绝该计划，重新定位/审看；不能静默重编码或把错误结果当通过。源变更、profile变更都必须重新检查，不能继承旧SHA的标记。
